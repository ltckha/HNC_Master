# Quy Tắc Dự Án: Tuyệt Đối Không Yêu Cầu Hoặc Tự Ý Đẩy Lên Git (Never Ask or Push Git Automatically)

## 🚨 NGUYÊN TẮC BẮT BUỘC (CRITICAL MANDATE)

1. **Tuyệt đối KHÔNG tự ý chạy lệnh Git Push hoặc yêu cầu User đẩy lên Git**:
   - Agent **TUYỆT ĐỐI KHÔNG** tự ý thực thi các lệnh `git push` hoặc chủ động yêu cầu/nhắc nhở User đẩy mã nguồn lên Git.
   - Việc đồng bộ và quản lý đẩy code lên Git (`git push`) là **100% quyền chủ động của USER**.
   - Agent chỉ hỗ trợ các thao tác liên quan đến Git khi và chỉ khi có **yêu cầu trực tiếp và rõ ràng từ USER**.
